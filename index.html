Connect Google Photos

Google only shares your picks with a page you've registered. It's a one-time job, about ten minutes.

  1. Open Google Cloud Console and create a project.
  2. Go to APIs & Services, then Library, and enable the Photos Picker API.
  3. Set up the OAuth consent screen as External and add your own Google account as a test user.
  4. Under Credentials, create an OAuth client ID of type Web application. Add as an authorised JavaScript origin.
  5. Copy the client ID and paste it below.

Only needed if picks fail with a “browser blocked the download” message. Deploy spool-proxy-worker.js to Cloudflare Workers and paste its address here.
